# Ejercicio 01: Modelado de Productos y Estado en Memoria

## Objetivo
Definir la estructura de datos de un producto en TypeScript y crear un catálogo en memoria que posteriormente servirá para responder a peticiones HTTP.

## Preguntas previas de razonamiento
1. ¿Qué información mínima identifica y describe un producto de forma unívoca?
2. ¿Qué tipos de datos primitivos de TypeScript corresponden a cada atributo?
3. ¿Cómo agrupamos múltiples productos para que un servidor pueda retornarlos?

## Cómo ejecutar
```bash
bun run exercises/01-modelado-productos/index.ts
```
